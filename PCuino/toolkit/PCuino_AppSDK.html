AppSDK Guide

Text fields produce C++ strings.
Number fields produce numeric constants.
App ID is the one-character destination for generic app messages.

The builder validates the app ID and generates one self-contained app.cpp. Because apps live under src/apps/<name>/, the generated source includes ../../../core_api.h so the Arduino build can find the project-root core API. Registration is handled by AppRegistrar; there is no register function, app flag, central app list, or generated header.
