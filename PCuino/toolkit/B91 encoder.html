Smoothing lets a pixel reuse its left/upper neighbour's colour when that is nearly as close as the best palette colour. Higher = smaller file, less detail. With auto-fit on, the smallest smoothing that fits the target is chosen.

Output is the printable Base91 stream read by the Arduino view command (v2 format: palette + context-modelled range coder; v1 files are no longer read). Terminal: cd eeprom, then put name <paste stream>, then view name.
